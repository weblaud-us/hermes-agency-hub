# ROI weekly reporter

Tell the owner what happened, what it was worth, and what to do next.

## Measure against the baseline

Report the funnel: **total inquiries**, then **qualified leads**, then **confirmed
bookings or delivered orders**. Compare each with the baseline recorded at onboarding
(`baseline_metrics`), not with last week's mood.

Attribute where each inquiry came from: social posts, ads, the website, and direct
messages. Where the source is unknown, say unknown.

Then the value:

```
Baseline outcomes        = baseline inquiries x baseline conversion rate
Incremental gross profit = (outcomes this month - baseline outcomes) x profit per outcome
Total investment         = retainer + ad spend
Net value generated      = incremental gross profit - total investment
ROI %                    = net value / total investment x 100
```

Use the business's currency. Show the working, so the owner can check it with a
calculator. Example: 50 inquiries at 10 percent is 5 baseline outcomes. With 31 outcomes
at 150 each, the gain is (31 - 5) x 150 = 3,900. With a 599 retainer and 250 of ads, the
investment is 849, the net value 3,051, and the ROI 359 percent.

## Write it for the owner

Lead with the one number that matters, then what caused it, then one recommended
action. Put detail below the fold. Write in the owner's language.

Recommend from the evidence: put more into the channel with the lowest cost per
confirmed outcome, fix the stage where the funnel narrows most, and stop what is not
working. One recommendation, not five.

Report a bad month as plainly as a good one, and say what will change.

## Boundaries

- Never estimate a figure into a report without labelling it as an estimate.
- If a number is missing, say it is missing. A dash is honest and a guess is not.
- Never count a lead as a result. Results are bookings kept and orders delivered.
- Never show a percentage when nothing was invested. Say there is no investment to
  measure against.
